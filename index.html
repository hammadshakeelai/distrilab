Strong Scaling vs Weak Scaling Insights

Amdahl's Law (Strong Scaling):
S(N) = 1 / [ (1 - P) + (P / N) ]
Fixed problem size. The sequential portion (1 - P) forms an impassable speedup asymptotic barrier 1 / (1 - P).
Gustafson-Barsis's Law (Weak Scaling):
S(N) = (1 - P) + P × N = N - (1 - P)(N - 1)
Expanding problem size. As processors grow, problem size scales so the serial fraction diminishes relative to total compute.
Karp-Flatt Metric: Quantifies experimental parallel code quality by extracting the empirically observed serial overhead \(e = \frac{1/S - 1/N}{1 - 1/N}\). An increasing \(e\) with core count pinpoints communication contention or lock serialization!

🍝 Concurrency & Deadlocks: Dining Philosophers Mutual Exclusion

The quintessential concurrency problem formulated by Edsger Dijkstra. Witness mutual exclusion, resource contention, and live circular-wait cycle detection in the Resource Allocation Graph (RAG).

Round Table & Resource Allocation Graph (RAG)

The 4 Coffman Deadlock Conditions

Deadlock occurs if and only if all four conditions hold simultaneously:

1. Mutual Exclusion: Forks cannot be shared; held by at most 1 philosopher.
2. Hold and Wait: Philosophers hold one fork while blocked waiting for the other.
3. No Preemption: Forks cannot be forcibly confiscated from eating philosophers.
4. Circular Wait: P₀ waits for F₁, P₁ waits for F₂ ... P₄ waits for F₀.

🌐 Consistent Hashing Ring Visualizer Distributed Storage

The foundational data partitioning technique behind Amazon DynamoDB, Apache Cassandra, and Discord voice gateways. Maps nodes and data keys to a 360° circular keyspace to minimize rebalancing when cluster topology changes.

3 Vnodes / Server
Hash Ring Keyspace (0 to 2³² - 1)

Per-Node Key Partition Distribution

Notice how virtual nodes (vnodes) smooth out the variance across servers:

Why Modulo Hashing Fails: With \(hash(k) \pmod N\), changing \(N \to N+1\) causes \(\approx \frac{N}{N+1}\) (up to 95%+) of all keys to move, triggering catastrophic cache stampedes. With Consistent Hashing, only \(\approx \frac{1}{N}\) of keys are redistributed!
